# Hooked-n-Reeled visual references

This directory stores approved visual references for the game. The folders are grouped by what the image is meant to guide.

## Folder structure

- `01-world/` — master world panorama, world map, biome overview, ocean zones
- `02-environment-assets/` — trees, plants, rocks, architecture, ocean props, underwater assets
- `03-locations/` — starter island, main port, remote outpost, landmarks
- `04-boats-and-equipment/` — boat families, customization, fishing equipment, fishing spots
- `05-atmosphere-and-water/` — lighting, weather, water and shoreline studies
- `06-biome-details/` — detailed images for each approved biome
- `07-approved-gameplay-references/` — later Roblox Studio blockouts and approved in-game screenshots

## File rules

- Use the exact filenames in `docs/VISUAL_REFERENCE_PLAN.md`.
- Keep original generated images unchanged.
- Add alternate generations with suffixes such as `_v2` and `_v3`.
- Do not commit temporary drafts, unrelated inspiration, or duplicate exports.
- Keep images at their original resolution where practical.
- Update the visual reference plan's image index when an image is approved and added.
- Concept art is guidance, not a production-ready Roblox mesh or texture.

The folders contain README placeholders so Git tracks the structure. Add the actual image files to the matching folders when ready.
