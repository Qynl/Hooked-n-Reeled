# Visual reference assets

Store approved generated concept images in this directory.

- Keep original generated images unchanged.
- Use the exact filenames in [the visual reference plan](../../../../docs/VISUAL_REFERENCE_PLAN.md).
- Add approved images here; do not commit temporary drafts or unrelated inspiration images.
- Use `_v2`, `_v3` suffixes for alternate generations.
- Update the image index in the plan when files are added.
- Concept images are visual guidance, not production-ready Roblox assets.

The initial image collection is planned but has not yet been generated.
