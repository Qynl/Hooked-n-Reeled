# Wild Sea — Game Design

An open-world fishing game for Roblox. Players roam between fishing grounds, cast into
the water, fight a reeling minigame, and pull up fish from a 16-tier rarity ladder that
runs from a 1-in-3 Common to a 1-in-1,500,000 Secret.

Place: **Wild Sea** (`placeId 78065626942509`)

Status: design phase. No gameplay code has been written yet.

## Core loop

1. **Cast** — click or tap water inside the equipped rod's range; a bobber arcs out.
2. **Bite** — after 2–8 seconds (zone dependent) the bobber dips and a sound fires. The
   player has a short reaction window to hook the fish.
3. **Reel** — a hold-input minigame: raise a marker to keep it overlapping a moving fish
   zone, build progress to 100%, and avoid the red tension band that snaps the line.
4. **Catch** — the server rolls a rarity tier and a weight, awards coins, updates the
   collection, and sends a catch card with the fish, its weight, its tier colour, and its
   literal odds ("1 in 300").
5. **Spend** — coins buy better rods (more Luck, easier reeling) and bait (zone-specific
   boosts), which is what makes the rare tiers reachable.

Mythic and above broadcast to the whole server.

## Rarity ladder

Sixteen tiers. Rolls run **rarest-first with independent checks**, so the advertised odds
are the true odds rather than weights that get normalised into something else. Luck from
rods and bait divides the denominators: a 2.0× Luck rod makes Legendary roughly 1 in 150.

| Tier | Odds | Value mult |
|---|---|---|
| Common | 1 in 3 | 1× |
| Uncommon | 1 in 7 | 3× |
| Rare | 1 in 20 | 8× |
| Super Rare | 1 in 50 | 20× |
| Epic | 1 in 120 | 50× |
| Legendary | 1 in 300 | 140× |
| Mythic | 1 in 750 | 400× |
| Divine | 1 in 1,800 | 1,200× |
| Celestial | 1 in 4,000 | 3,500× |
| Void | 1 in 9,000 | 10,000× |
| Abyssal | 1 in 20,000 | 30,000× |
| Primordial | 1 in 45,000 | 90,000× |
| Eldritch | 1 in 100,000 | 280,000× |
| Godly | 1 in 250,000 | 900,000× |
| Transcendent | 1 in 600,000 | 3,000,000× |
| Secret | 1 in 1,500,000 | 10,000,000× |

Tiers step by roughly 2.2×, which keeps the low half reachable within a session while the
top three stay genuine chase items.

Each zone draws only from its own fish pool, and a zone's pool need not cover every tier —
the deepest water is where the top of the ladder lives.

> quality gate the rare tiers, lock zones behind level or coins, or allow open travel with
> a minimum fishing level per zone.

Whatever we pick, the map is generated by an idempotent `WorldBuilder` script that ships in
the repo, so the world can be rebuilt from source instead of being hand-placed one part at
a time.

## Architecture

**Server-authoritative.** The server owns the bite timer, the reel state, the rarity roll
and the weight roll. The client sends input flags only — cast requests and "reeling: true/
false" — and those are rate-limited. Nothing in the client can name its own fish or its own
rarity.

**Data.** `PlayerData` wraps DataStore with periodic autosave, save on leave, and
`BindToClose`. It stores coins, inventory (species → count and best weight), equipped rod
and bait, total catches, and the discovered-species set. If Studio's API access is off it
falls back to in-memory so playtests still work.

**Remotes.** `ReplicatedStorage.Remotes` carries cast requests, reel input, reel start,
catch results, shop requests and data sync.

## Source of truth and syncing

The repo is the source of truth; Studio is the runtime. No Roblox toolchain is installed on
this machine (no Rojo, Aftman, Wally, Selene), so rather than requiring a binary install and
a Studio plugin before any game code exists, scripts are pushed into the open Studio session
over the Studio MCP server and pulled back when they change there. Adopting Rojo later is
mechanical — add a `default.project.json` — and nothing here blocks it.

## Verification

- **Syntax sweep** — load every script in the place programmatically and report parse errors.
- **Odds audit** — run the roll function 100,000 times and print the actual tier frequencies,
  confirming they land near 1/3, 1/7, 1/20, 1/300, 1/1,500,000 rather than trusting the maths.
- **Playtest** — run a full cast → bite → reel → catch cycle in a Server playtest, read the
  output log for errors, and confirm a catch card fires with a tier.

## Out of scope for the first slice

Boats, quests, pets, trading, and a full fishing-index UI beyond a collection count.

## Publishing

The place is not published automatically. `save_place` creates a new published version, so
saving is a developer decision, not a side effect of building.
