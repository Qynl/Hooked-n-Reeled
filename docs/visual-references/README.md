# Hooked-n-Reeled visual references

All visual reference images for Hooked-n-Reeled belong under this directory in `docs/`. These are project design references, not Roblox build-skill assets.

## Folders

- `01-world/` — overview, world map, biome overview and ocean zones
- `02-environment-assets/` — nature, rocks, architecture, ocean props and underwater assets
- `03-locations/` — starter island, main port, remote outpost and landmarks
- `04-boats-and-equipment/` — boat family, customization, fishing equipment and fishing spots
- `05-atmosphere-and-water/` — weather, lighting, water and shoreline
- `06-biome-details/` — individual biome environment references

## Rules

- Use the exact filenames listed in [the visual reference plan](../VISUAL_REFERENCE_PLAN.md).
- Keep approved originals unchanged. Use `_v2`, `_v3` for alternate generations.
- Do not put these project images in `skills/`.
- Update the image index in the visual reference plan when an image is added and approved.
- Concept art guides production; it is not itself a finished Roblox asset.
