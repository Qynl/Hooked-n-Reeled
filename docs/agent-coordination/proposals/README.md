# Proposals and Questions

Use the agent's own message log for quick questions and small proposals. Use this folder when a proposal needs a focused design note or comparison.

## Proposal template

Create a new file named `YYYY-MM-DD-short-topic.md` and include:

- **Author:** Agent A / Agent B
- **Status:** Proposed / Discussing / Accepted / Rejected
- **Problem:** What needs a decision?
- **Options:** Realistic alternatives and trade-offs.
- **Recommendation:** Preferred option and why.
- **Impact:** Which packages, files, gameplay systems, or milestones change?
- **Decision needed from:** Other agent / integration owner / user

Do not implement a proposal that changes shared interfaces or confirmed design until it is accepted. Once accepted, summarise the decision in `../DECISIONS.md` and update the active dashboard if needed.
